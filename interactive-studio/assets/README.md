This directory is for the optional `Sleigh-Ride-120.dms` practice pack. The Band Studio automatically loads the pack from this path when deployed, allowing students to open Sleigh Ride directly from GitHub Pages.

**Rights note:** A GitHub Pages deployment from this public repository makes uploaded files publicly accessible. Only upload scores, recordings, or arrangements here when you have the right to distribute them publicly. Otherwise, keep the pack in a school-approved restricted channel for students.
